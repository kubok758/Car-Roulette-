# 🎰 CAR ROULETTE — рулетка автомобилей

Крути автомобильный слот-автомат и узнай, какая машина тебе выпадет: от Benz Patent-Motorwagen 1886 года и «Копейки» до Bugatti La Voiture Noire, существующей в единственном экземпляре.

**В базе 2 322 поколения — 1 203 модели 159 марок из 29 стран.** Каждая запись — отдельное поколение модели с годами выпуска, кузовом, классом, приводом, типом силовой установки, диапазоном мощности и редкостью. Для 891 записи есть короткий проверенный факт.

## Возможности

- **Настоящие барабаны.** Марка, модель и поколение прокручиваются и останавливаются по очереди со щелчками и замедлением. Кнопка «Стоп» докручивает барабаны сразу.
- **Честный рандом.** Случайные числа берутся из `crypto.getRandomValues`. Есть два режима: «По редкости», где редкость сначала разыгрывается по весам, и «Равные шансы». Режим «Без повторов» помогает собрать коллекцию. Окно «Шансы» показывает вероятности для текущего пула.
- **Шесть редкостей**: обычная, необычная, редкая, эпическая, легендарная и мифическая. У каждой свой цвет, звук и эффекты; мифические машины выпущены единицами или считаными десятками экземпляров.
- **Фильтры**: страна, марка, кузов, класс, эпоха, привод, силовая установка, редкость и мощность. Счётчик сразу показывает, сколько машин подходит. Есть готовые подборки: «Японская классика», «Суперкары», «СССР и Россия», «Маслкары» и другие.
- **Карточка машины**: характеристики, номер поколения («3 из 9»), шанс выпадения, факт, поиск фото, видео и статьи в Википедии (Google/YouTube или Яндекс на выбор), ссылка «Поделиться», которая открывает именно эту машину.
- **История** с поиском и группировкой по дням, **гараж** избранных машин, **каталог** всей базы. Поиск понимает латиницу, кириллицу и транслит: «тойота супра» найдёт Toyota Supra.
- **Коллекция** с прогрессом по маркам и редкостям, **35 достижений**, **статистика** (активность за 14 дней, распределение редкостей по сравнению с ожидаемым, любимые марки, страны и эпохи) и **машина дня**.
- **Работает без интернета и без сервера.** Можно открыть `index.html` прямо с диска; на хостинге приложение ставится на телефон как PWA и работает офлайн.
- **Прогресс хранится только в браузере.** Есть резервная копия в JSON и загрузка из неё. Прогресс из прошлой версии переносится автоматически.
- **Доступность**: управление с клавиатуры (Пробел или Enter — крутить, F — в гараж, Esc — закрыть окно), учёт системной настройки «Уменьшить движение», адаптивная вёрстка от 320 px.

## Как запустить

Самый простой способ — открыть `index.html` в браузере.

Чтобы заработали офлайн-режим и установка на телефон, нужен любой статический сервер:

```bash
npm start            # npx serve на http://localhost:4173
# или
python3 -m http.server 4173
```

### Публикация на GitHub Pages

Settings → Pages → Build and deployment → **Deploy from a branch** → ветка `main`, папка `/ (root)`. Сборка не нужна: сайт состоит из статических файлов.

## Структура проекта

```
index.html                 разметка страницы
assets/css/app.css         стили
assets/js/core.js          логика без DOM: рандом, фильтры, шансы, достижения, сохранения
assets/js/fx.js            звук (Web Audio), вибрация, конфетти
assets/js/app.js           интерфейс
assets/data/cars.js        собранная база (генерируется, вручную не редактируется)
assets/fonts/              шрифт Unbounded (SIL Open Font License)
data/*.txt                 исходники базы — их и нужно править
data/README.md             формат файлов базы
scripts/build-data.mjs     проверка и сборка базы
tests/                     тесты (node --test)
sw.js, manifest.webmanifest  PWA и офлайн-режим
```

## Как добавить или исправить машину

1. Откройте нужный файл в `data/` (они разбиты по странам) и отредактируйте строки — формат описан в [`data/README.md`](data/README.md):

   ```
   @Toyota | JP | aka=Тойота
   Camry | sedan | D | F | P/H
   - XV70 | 2017-2024 | 150-305
   ```

2. Соберите базу: `npm run build`. Скрипт проверит каждую строку (годы, мощность, справочники, дубликаты, смешение латиницы и кириллицы) и покажет ошибки с номерами строк.
3. Запустите тесты: `npm test`.

Нужен только Node.js 18 или новее; зависимостей нет.

## Тесты

```bash
npm test        # логика ядра и проверка базы
npm run check   # assets/data/cars.js совпадает с исходниками в data/
```

Те же проверки запускаются в GitHub Actions на каждый push.
