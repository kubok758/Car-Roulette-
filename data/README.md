# База автомобилей

Исходники базы — обычные текстовые файлы `*.txt` в этой папке. Скрипт
`npm run build` (он же `node scripts/build-data.mjs`) проверяет их и собирает
компактный `assets/data/cars.js`, который загружает приложение. Руками
`cars.js` не правят.

## Формат

```
# Комментарий

@Toyota | JP | aka=Тойота
Camry | sedan | D | F | P/H
> Факт о модели (показывается для всех поколений без своего факта).
- XV10 | 1991-1996 | 120-188
- XV70 | 2017-2024 | 150-305
- XV80 | 2024- | 225-232 | f=H
> Факт о конкретном поколении.
```

### Марка — строка с `@`

`@Название | Страна | ключ=значение…`

| Ключ    | Что значит                                                    |
| ------- | ------------------------------------------------------------- |
| `aka`   | Другие названия для поиска (например, русское написание)      |
| `floor` | Минимальная редкость всех машин марки (например, у Ferrari — `epic`) |

### Модель — строка без префикса

`Название | Кузова | Класс | Привод | Топливо | ключ=значение…`

Ключи: `r` — редкость всех поколений, `c` — страна, `aka` — другие названия для поиска.

Несколько значений перечисляются через `/`: `hatch/wagon`, `F/A`, `P/D/H`.

### Поколение — строка с `-`

`- Название | Годы | Мощность | ключ=значение…`

* **Годы**: `1991-1996`, `2024-` (выпускается сейчас) или `2016` (один год).
* **Мощность** в л.с.: `120-188` (от базовой до топовой версии), `300` или `?`.
* Ключи `b`, `k`, `d`, `f`, `c` переопределяют кузов, класс, привод, топливо и
  страну модели для этого поколения; `r` задаёт редкость явно.

### Факт — строка с `>`

Относится к последней модели или поколению. 20–320 символов, заканчивается точкой.
Пишите только то, в чём уверены.

## Справочники

| Поле   | Значения |
| ------ | -------- |
| Кузов  | `sedan` седан, `hatch` хэтчбек, `lift` лифтбек, `wagon` универсал, `coupe` купе, `cabrio` кабриолет, `roadster` родстер, `xover` кроссовер, `suv` внедорожник, `pickup` пикап, `minivan` минивэн, `van` фургон |
| Класс  | `A` `B` `C` `D` `E` `F` — сегменты, `S` спорткар, `SC` суперкар, `HC` гиперкар, `LCV` коммерческий |
| Привод | `F` передний, `R` задний, `A` полный, `4` полный 4×4 (рамные внедорожники) |
| Топливо | `P` бензин, `D` дизель, `H` гибрид, `PH` плагин-гибрид, `E` электро, `FC` водород |
| Страна | коды из `COUNTRIES` в `assets/js/core.js` (`JP`, `DE`, `US`, `UK`, `RU`…) |

## Редкость

Если `r` не указан, редкость считается автоматически:

* классы A–D и коммерческие — обычная, E и спорткары — необычная, F — редкая,
  суперкары — эпическая, гиперкары — легендарная;
* машины, выпуск которых закончился до 1970 года, на ступень реже;
* не ниже, чем `floor` марки.

Мифическая редкость назначается только вручную — для машин, выпущенных
единицами или несколькими десятками экземпляров.
